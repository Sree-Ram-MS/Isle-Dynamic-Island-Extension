👆 Interactive preview — hover the notch to open it, move away and it closes. Try play, Drink, and the to-do list.

Everything you glance at, in one place.

Hover the notch to open it. Move away and it closes. Nothing to arrange, nothing to pin — it lives inside GNOME Shell, at the top of your screen.

🎵

Music from any player

Spotify, YouTube in Firefox or Chrome, VLC, Rhythmbox — anything that speaks MPRIS. See what’s playing, pause, skip and seek without switching windows. The playing player wins, so a YouTube tab is never hidden behind a paused app.

🎤

Synced lyrics

Lyrics come from LRCLIB, the free community library. The current line sits in a pill on the Lyrics page — and if you close the notch from there, the line moves into the minimized notch and keeps singing along, the notch widening to fit it.

🖼

Wallpaper switching

Browse thumbnails of your pictures and the system backgrounds, tap one, and it’s applied — light and dark both. Thumbnails load asynchronously at thumbnail size, so the page never weighs the shell down.

🧭

Pages you choose

Hover the page dots and they turn into an icon bar for every page; pages slide as you move between them. Don’t use a page? Switch it off in Settings → Pages and it’s gone from the notch.

🍅

Focus timer

Start a Pomodoro session and watch it count down in the notch. Set your own focus and break lengths in Settings; a soft chime tells you when to rest.

💧

Water reminder

Set your bottle size and daily goal. Isle reminds you during your chosen hours — set right inside the notch under Water → Settings — and tracks how much you drank today.

🗄

File & text shelf

Keep files and snippets close on the Shelf, then copy or open them when you need them. GNOME doesn’t let shell extensions receive drags from other apps, so the Shelf honestly uses Add files / Paste / Copy instead.

✓

To-do with reminders

Jot a task, give it a time, and the notch taps you on the shoulder when it’s due. Tasks are stored locally, on your machine.

📅

Calendar reminders

A month view and upcoming events in the notch, with reminders — no need to keep a calendar window open all day.

📊

Hardware monitor

CPU, RAM, GPU, network (in honest KB/s) and disk — with used/total size — at a glance, in the same place as everything else.

🔋

Battery, Wi-Fi & headphones

The little ring tells the story at a glance: green while charging with a bolt in the middle, blue at 100%, red when low. Plus a quick peek when you lose your connection, pair your earbuds, or toggle Caps Lock — and no fake battery numbers when a device isn’t there.

A small companion that knows when to rest.

When nothing is happening, the clock fades and a pair of eyes appears. They doze off after a while, and come back when you return.

  • Native to GNOME. It runs inside GNOME Shell itself — not a floating web app — so it stays on top on Wayland, in the right place, without window tricks.
  • Your data stays here. Tasks, water logs and shelf items are stored on your computer, in ~/.local/share/nusa-notch.

Get Isle for Ubuntu

Download the ready-made .deb from GitHub Releases, or build it from source — about a minute either way, and no admin rights are needed until the install step itself.

1

Get the code

Clone the repository from GitHub:

git clone https://github.com/Sree-Ram-MS/Isle-Dynamic-Island-Extension.git cd Isle-Dynamic-Island-Extension
2

Build & install the .deb

This builds nusa-notch_1.6.2_all.deb and installs it with apt (if you downloaded the release .deb instead, install that file the same way):

./build-deb.sh sudo apt install ./dist/nusa-notch_1.6.2_all.deb
3

Log out once, then enable

GNOME Shell on Wayland only loads a new extension at login, so log out and back in once, then run:

nusa-notch-enable # or, equivalently: gnome-extensions enable nusa-notch@linux-clone

The notch appears at the top of your screen. Hover it to open it.

Trying it without installing? Run ./dev-install.sh instead — it copies the extension to your user folder only (no sudo, no .deb), which is handy while tweaking. To remove the .deb version later: sudo apt remove nusa-notch.

# Something not working? Check the logs: journalctl -b -o cat /usr/bin/gnome-shell | grep -iE "nusa|JS ERROR" gnome-extensions info nusa-notch@linux-clone

An honest note.

Isle for Linux is an unofficial, personal project inspired by Nusa for Windows by its independent developer. No code or assets from the Windows app are included — this is original code, released under the MIT license, built to bring the same living-notch idea to Ubuntu.

This is an early version. You may run into bugs, and some laptops may behave a little differently. If something breaks, please open an issue on GitHub — every report helps.

Only get it from the GitHub repository linked on this page. Isle for Linux is provided “as is”, without warranties of any kind.

Questions

Is Isle for Linux free?

Yes. It’s open, original code under the MIT license, on GitHub. The Windows original is a separate project by a different developer — see its own page for its terms.

Which Ubuntu and GNOME versions work?

The extension supports GNOME Shell 45–50. The tested target is Ubuntu 26.04 with GNOME 50; other GNOME 45–50 desktops should work too.

Does it work on Wayland?

Yes — that’s the point of building it as a GNOME Shell extension. It lives inside the shell itself, so it stays on top and in place on Wayland without XWayland window tricks. You do need to log out and back in once after installing, because Wayland loads new extensions at login.

Which music players work?

Any MPRIS player: Spotify, VLC, Rhythmbox, and browsers like Firefox and Chrome — including YouTube. If several players are open, the one that’s actually playing is shown.

Why doesn’t a song have lyrics?

Lyrics come from LRCLIB, a free community library. Popular songs almost always have synced lyrics; some local or newer songs don’t yet. You can turn lyrics off entirely in Settings.

Why can’t I drag files onto the Shelf like on Windows?

GNOME Shell extensions can’t receive files dragged from other apps — it’s a platform limit, not a missing feature. The Shelf therefore uses Add files, Paste and Copy, which work reliably.

How do I open Settings, quit, or uninstall?

Settings: the gear in the notch, Extension Manager, or gnome-extensions prefs nusa-notch@linux-clone. Disable: gnome-extensions disable nusa-notch@linux-clone. Uninstall the .deb: sudo apt remove nusa-notch.

How do I update?

Download the newest .deb from GitHub Releases and install it — or pull the latest code, rebuild with ./build-deb.sh, install, and log out/in once. Your tasks, water log and shelf are kept.

Privacy

Isle doesn’t collect personal data and has no analytics. Your tasks, calendar reminders, water log, shelf and settings are saved only on your computer, in your user folder (~/.local/share/nusa-notch).

When you use lyrics, it sends the song’s title, artist, album and length to LRCLIB (lrclib.net) to find matching lyrics. Nothing else leaves your computer — and lyrics can be switched off in Settings.
